# dmenu module — no Rofi

`~/.local/bin/i3-theme-dmenu` launches the user's existing `dmenu_run`, selecting dynamic `-nb/-nf/-sb/-sf` colors. Their existing centered dmenu binding used `-c`. For stock dmenu, set `I3_THEME_DMENU_CENTER=0` in the i3 binding. It does not install Rofi or change the key used to switch language layouts.
