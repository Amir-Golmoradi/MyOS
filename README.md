## Safety / installation blockers

1. `hosts/asus-tuf/hardware-configuration.nix` contains a **failing assertion**.
   REPLACE it with the file generated by the NixOS installer after mounting
   your *real* target filesystems. `asus-tuf-preflight` is evaluation-only
   with deliberately invalid disk labels; NEVER install the preflight host.
2. Actual i3 config, Polybar, picom, fish prompt and Catppuccin theme scripts
   are included from user archives. Kitty's uploaded files were broken symlinks
   into a different dotfiles repo; Dunst, keyd, ~/.Xresources, and personal
   wallpaper JPEGs were NOT provided. See migration/DESKTOP-INTEGRATION.md.
3. No flake.lock is bundled; create it on Arch with `nix flake lock`.
4. Must evaluate *your pinned* Nixpkgs packages and actual NVIDIA hardware
   before reformatting. The ZIP authoring environment cannot run Nix itself.
5. Kotlin/Native downloads its compiler through the Kotlin Gradle plugin when
   first building Kotlin/Native targets. The JetBrains Kotlin LSP from your
   Arch AUR is NOT equivalent to the fallback nixpkgs language server.
6. This is **not** a backup. Your company projects, secrets and documents are
   NOT included. Verify a real restore from your independent backup first.

## Preflight on Arch (fish)

Extract into a new folder and merge carefully with your existing
`~/arch-to-nixos`; don't overwrite your existing lock/dotfiles blindly.
Use the ZIP contents as the proposed modular replacements.

```fish
cd ~/arch-to-nixos
# If new files are missing from Git index, Nix won't see them.
git add -N .
nix flake lock
nix eval .#nixosConfigurations.asus-tuf-preflight.config.system.build.toplevel.drvPath --raw
# Optional full build on Arch (large and may fetch many dependencies):
nix build .#nixosConfigurations.asus-tuf-preflight.config.system.build.toplevel --no-link
```

Caveat: the preflight config checks Nix evaluation with fake filesystem labels;
it is not proof of bootability and cannot substitute actual hardware checks.
Upstream Elio and Bookokrat may require compilation / additional dependencies.

## NixOS installer outline (ONLY after verified backups)

Boot installer, confirm precise disk identities, partition/format as you intend,
mount the target under `/mnt`. Then run:

```fish
sudo nixos-generate-config --root /mnt
```

Copy the newly generated `/mnt/etc/nixos/hardware-configuration.nix` to
`hosts/asus-tuf/hardware-configuration.nix` in the prepared repository.
Copy the complete flake directory to `/mnt/etc/nixos` (including flake.lock)
and ensure Git tracks every necessary file. Install ONLY the real host:

```fish
sudo nixos-install --flake /mnt/etc/nixos#asus-tuf
```

Set a password for user `amirgm` within the installed system before first boot;
see the official NixOS installation manual for entering the installed system.
Never use `asus-tuf-preflight` for installation.

## After first boot

```fish
sudo nixos-rebuild switch --flake /etc/nixos#asus-tuf
nix develop /etc/nixos#java-kotlin
nix develop /etc/nixos#rust
nix develop /etc/nixos#c-cpp
```

Git controls the `.nix` SOURCE history; NixOS boot generations allow a separate
system rollback. Déjà Dup protects personal files (not a system rollback).
See `migration/UNRESOLVED.md` for differences from Arch.
